# 🎨 Color Palette Generator

A beautifully crafted, modern web tool for generating, testing, and saving color palettes. Inspired by Moroccan design elements and enhanced with trendy 2025 UI/UX effects such as glassmorphism, gradient layers, and dark/light modes. Ideal for designers, developers, and creatives who want style and functionality.

---

## ✨ Features

- 🎨 Generate unique 5-color palettes
- 🔒 Lock specific colors while randomizing others
- 📋 Copy HEX or RGB codes to clipboard
- 💾 Save your palettes with names and tags
- ❤️ View and manage saved/favorite palettes
- 🧪 WCAG Contrast Checker with live preview
- 🌗 Light/Dark theme toggle
- 🎚️ Switch between HEX and RGB modes
- 📤 Export palette to CSS, SCSS, Tailwind, or JSON
- 🧊 Uses modern UI: gradients, blur effects, glassmorphism
- 🇲🇦 Moroccan-inspired UI design
